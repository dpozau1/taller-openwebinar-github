# taller-openwebinar-github
Repositorio con información para alojar un proyecto de documentación en github.

# Documentación

Repositorio destinado a almacenar la documentación del proyecto.

## Contenido

* Documentación general
* Guías y procedimientos
* Notas técnicas
* Referencias

## Estructura

```text
docs/
├── guias/
├── tecnica/
└── referencias/
```

## Uso

Los documentos están escritos principalmente en formato Markdown (`.md`) para facilitar su lectura y mantenimiento en GitHub.

## Contribución

Para añadir documentación:

1. Crear o modificar el archivo correspondiente.
2. Mantener una estructura clara y sencilla.
3. Subir los cambios al repositorio.
